# Data_for_DGCC
1.This attachment provides supplementary experimental descriptions for the article 
entitled "A CGH-Based Calibration Method Using Dammann Grating Diffraction Arrays for High-Precision Distortion Correction".

2.We provide two actual images captured by the star sensor, named "CGH-based distortion_1" and "CGH-based distortion_2". 
The frame rate of the star sensor is 10 Hz, and the time interval between these two images is approximately 0.1 s.

3.The original GDS design file of the Dammann grating CGH is named "CommonAB_V5_20250914". 
This file contains two Dammann gratings; the smaller one on the left is the grating used in the experiment.

4.During fabrication, the material used was Corning fused silica 7980, with a refractive index of 1.45701793 at 632.8 nm. 
The etching depth is 0.692314194 µm (±5 nm), and the linewidth error is ±10 nm.
